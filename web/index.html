How it works

A converter that runs where your file is.

Online converters work by uploading your document to their server. DocShift brings the converter to the document instead: this page loads it into your browser, and your file is read and the converted one written without either of them going anywhere.

Nothing is uploaded

There is no DocShift server to upload to. Close the tab and the only copies are the ones on your computer.

Same engine as the app

The code that converts here is, line for line, the code inside DocShift for Windows, including its checks for damaged, password-protected and mislabelled files.

Honest about gaps

If a page cannot be converted, or a header cannot be drawn, the rest still are and DocShift names what is missing instead of quietly handing back less than you gave it.

Word to PDF, without Word

Nothing here owns a copy of Word, so DocShift draws the document itself: headings, formatting, lists, tables, pictures, page size and breaks. Headers, footers and footnotes it cannot draw, and says so.

Free, for good

No account, no watermark, no limit on pages or files. The source is public domain.

Windows app

Rather have an app?

DocShift for Windows is the same converter as a single program: both directions, nothing to download on each visit, faster on long documents, and it works offline.

Download for Windows Source on GitHub

Unzip it and run DocShift.exe — there is no installer. The first time, Windows SmartScreen warns about an unknown publisher, because the file is not code-signed: More info → Run anyway.
